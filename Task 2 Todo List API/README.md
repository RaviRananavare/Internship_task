# Todo List API

A simple REST API for managing todos using Flask and in-memory storage.

## Features

- Create todos
- List all todos
- Get a specific todo
- Update todos
- Delete todos
- Input validation
- Automatic ID generation
- Automatic creation timestamps
- In-memory storage
- Automated test suite
- 97% total test coverage

## Requirements

- Python 3
- Flask
- Coverage
