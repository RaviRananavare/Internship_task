\# Data Validator



A flexible JavaScript data validation library that validates objects against user-defined schemas.



\## Features



\- Required field validation

\- String validation

&#x20; - Minimum length

&#x20; - Maximum length

\- Number validation

&#x20; - Minimum value

&#x20; - Maximum value

\- Email format validation

\- URL validation

\- ISO date validation

\- Optional fields

\- Custom error messages

\- Multiple validation errors

\- Clear validation results
