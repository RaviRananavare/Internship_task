\# URL Shortener



A simple URL shortening service built with Node.js and Express.



\## Features



\- Generate unique 6-character short codes

\- Shorten long URLs

\- Redirect short URLs to original URLs

\- Handle duplicate URL submissions

\- Support custom aliases

\- URL information endpoint

\- Click tracking

\- Input validation

\- In-memory URL storage

\- Jest and Supertest test suite



\## Requirements



\- Node.js

\- npm
